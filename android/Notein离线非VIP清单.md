# Notein 离线 / 非VIP 功能清单（hydronotes 实施依据）

> 来源：`Notein_res_资源与功能清单.md`（Notein v1.3.166 反编译资源，com.orion.notein）。
> 过滤规则：**去除一切联网能力**（云同步 / 网盘备份 / MSAL 账号登录 / 自动更新 / 问题反馈 / AI 助手 / 划词翻译词典）**与一切 VIP 专属功能**（图形笔 / 激光笔 / 无界笔记 / 双向链接 / 导入字体 / 矢量 PDF / 去水印导出 / 会员中心等）。
> 其余离线、免费即得的功能，作为 hydronotes（本地手写笔记 App）的对标实施清单。
>
> 现状标记：`✅` hydronotes-flutter 当前已有　`🔲` 仍缺　`⏳` 部分实现/待接活
> 现状依据：`STATUS.md`（批次1–17）+ `功能清单_核对版.md`。
